# adv80sGD：シナリオエディタの使い方

## 開き方と画面の作り

1. Godot の上の画面切り替え（2D・3D・Script の並び）から「adv80s」を開く。出ないときは、プラグインが有効か確かめる。
2. 左上の種類から「シナリオエディタ」を選ぶ。
3. 初めてなら、シナリオを置くフォルダを決める（セットアップで作ったゲームなら既に決まっている。既定 `res://game/scenario`）。

エディタは HyperCard のように、カードを開いて奥へ進む作りです。上のパンくずで、いまどこにいるかが分かり、押すと戻れます。

```text
フォルダ › ゲーム（シナリオの一覧） › シナリオ（チャプターの一覧） › チャプター（シーンの一覧） › シーン
                                                                         ├ セリフエディタ（JSON・Ink）
                                                                         └ コマンドエディタ
```

| 画面 | 左 | 右 |
| --- | --- | --- |
| ゲーム・シナリオ・チャプター | 共通の設定（タブ：初期設定・変数・コマンド・セリフ・アセット・その他。ゲームにはほかにタイトル・おわり・おまけ・システム） | カード（1 枚が 1 つのシナリオ・チャプター・シーン。シーンには背景の小さな絵） |
| シーン | シーンの設定（名前・背景・もの・出口・スプライト） | 右上：セリフの一覧、右下：コマンドの一覧 |

データは JSON シナリオのファイルそのものです。エディタで書いても、手で書いても、ゲームは同じように読みます。エディタの外で書き換えたファイルは、エディタの窓に戻ったときに読み直されます。

## シナリオ・シーンを作る

**作る**：一覧の「＋ 新規作成」で、名前と ID を入れて作ります。ID は名前から作ったものが先に入っていて、書き換えられます（英小文字・数字・`_`・`-`）。新しいシナリオには、最初のチャプターと開始のシーンも一緒にできます。

**カードの操作**

| 操作 | やり方 |
| --- | --- |
| 開く（次の一覧へ） | ダブルクリック、Enter |
| 選ぶ | クリック（Ctrl+クリックで足す・外す、Shift+クリックで範囲、Ctrl+A ですべて） |
| 並べ替える | ドラッグ（カードの右半分に落とすと後ろ、左半分なら前） |
| 名前を変える | F2（表示名だけ。ID はそのまま） |
| ID を変える | 右クリック →「ID を変更…」（参照も書き換える） |
| 複写する | 右クリック →「複写…」「別のシナリオへ複写…」 |
| 削除する | Delete（シナリオはフォルダごと、チャプターはファイルを OS のごみ箱へ） |

- **開始シナリオ**：ゲームの一覧の左上の「開始シナリオ」で選ぶと、そのシナリオの `start` からゲームが始まります（カードに「▶」が付く）。
- **複写**：シーンと会話の ID は新しくなり（`_copy`、`_copy_2`…）、複写したものの中の参照も付け替わります。外への参照はそのままです。
- 作る・複写・削除のたびに、プロジェクト設定の `scenarios` が書き直されます。自分で直す必要はありません。

**シーンの設定**（シーンを開いた画面の左）

- 背景や曲など素材の ID は一覧から選べます。画像には小さな見本が付き、曲・効果音・ボイスは ▶ で試しに鳴らせます。一覧にない値は「（手で入力…）」で書けます。
- 見つからない ID は赤字になります。
- 「範囲を絵で決める…」で、背景の上をドラッグしてもの・出口の範囲（`region`）を決めます。
- 手順（入ったとき・動詞ごとの反応）はここではなく、右下のコマンドから書きます。

## セリフ・選択肢・コマンドを書く

シーンを開いた画面の右側から、二つのエディタに入ります。

| | セリフ（右上） | コマンド（右下） |
| --- | --- | --- |
| 中身 | このチャプターの会話（`dialogues`）と、このシナリオの Ink | 入ったとき（`enter`）、初めて入ったとき（`first`）、シーン全体の動詞、もの・出口の動詞 |
| 作る | JSON か INK を選んで「セリフを作成」 | 「コマンドを作成」（「＋ もの」「＋ 出口」でシーンに足せる） |
| 開く | ダブルクリック | ダブルクリック |

コマンドの動詞は、標準の動詞とプロジェクト設定・シナリオの `verbs` から選びます。「使うもの」を書くと `USE+ドア` のような組み合わせの反応になります。

**手順のエディタ**（セリフとコマンドで共通）

手順を木で並べ、列は「種類・内容・条件」です。

- 「＋ 手順を追加」で、選んでいる手順の後ろ（条件分岐・選択肢の項目なら中）に足します。種類は、地の文・台詞・条件分岐・選択肢・選択肢の項目・変数の計算・移動・会話の呼び出し・サブシーンの呼び出し・サブシーンから戻る・Ink のノット・演出とシステム（出力イベント）・そのほか（JSON）。
- 「削除」「↑」「↓」で消す・動かす。
- 演出・システムは、イベントの名前を一覧から選び、引数をイベントごとのフォームで書きます。素材・シーン・持ち物の ID は一覧から選べます。
- 木の下の欄で、台詞の `id`・`voice`、選択肢の `id`、項目の `id`・`once` を書きます。
- 「JSON」を入れると、手順の JSON を直接書き換えられます（「JSON を反映」で戻す。誤りは行番号つきで出る）。

**式エディタ**：条件（`if`・`when`）と変数の計算（`let`）の項目の「式…」で開きます。打つと候補が出（Ctrl+Space でも）、↑↓で選んで Enter・Tab で入れます。誤りのある式は決定できません。

**Ink のセリフ**：`.ink` の文章をそのまま書き、「Ink をコンパイル」で `.ink.json` を作ります（エディタ設定 `adv80s/inklecate_path` に inklecate の場所を書いておく）。`call_scene("` のあとにはサブシーン、`goto_scene("` のあとにはシーンの候補が出ます。

**保存**：画面ごとの「保存」か Ctrl+S。ほかの画面へ移るときは、書いたものを保存してから移ります。会話ID を変えて保存すると、呼んでいる手順（`call`、`talked(…)` など）も書き換わります。

## ID を確かめる・元に戻す・ほかの画面

**ID の確認**（右上）：プロジェクト設定とすべてのシナリオ、Ink のソースから、見つからない素材・シーン・持ち物の ID を一覧にします。

- 行をダブルクリックすると、そのシーンを開きます。上の「種類」「ファイル」で絞り込めます。
- 行を選んで、下の「直す ID」で候補を選び、「選んだ行を直す」「同じ ID をまとめて直す」で書き換えます（まとめて直すときは、書き換える場所を確かめてから）。
- 「書き出す…」で CSV かテキストにできます。
- 一覧を出しているあいだは、保存するたびに確かめ直します。

**元に戻す**：右上の「↶ 元に戻す」「↷ やり直す」（Ctrl+Z、Ctrl+Shift+Z・Ctrl+Y）で、保存・作る・複写・削除・名前や ID の変更・並べ替え・移すを一つずつ戻せます（最大 100。エディタを閉じると消える）。文字を書く欄の中では、その欄の元に戻すが先に効きます。

**「adv80s」画面のほかの種類**（左上で切り替える）

| 種類 | 使いどころ |
| --- | --- |
| プロジェクト設定 | `adv80s.project.json` をフォームで書く |
| テンプレート | 画面の見た目（`template.json`）を書く |
| マニフェスト | 素材の一覧を見る・直す |
| 変数の一覧 | JSON と Ink の変数・定数を、読む場所・書く場所つきで見る（打ち間違い探しに） |
| シーングラフ | シーンどうしのつながりを図で見る |
| セットアップ | 新しいゲームのフォルダ一式を作る |

まとめての確認（書き方、変数、素材、どこからも来られないシーン）は、ドック「adv80s」の「マニフェストを生成」で行います。

## 確かめて動かす

**このシーンから実行**：シーンを開いた画面の「▶ このシーンから実行」で、タイトルとオープニングを飛ばしてそのシーンから動かします（デバッグビルドだけ）。会話の画面の「▶ ここから実行」なら、選んでいる手順から（Ink はカーソルのあるノットから）始めます。

- 「設定を先に」に印を付けると、始める場所より前の `set`・`let` を先に動かします。あわせて「条件も」に印を付けると、前の「もし」の中の設定も動かします。入った値はお知らせとメッセージログに出ます。

**ひな形**：フラグ・変数・持ち物をそろえた状態で試したいときに使います。

1. 「ひな形…」で、名前と「名前 = 値」（変数）「ID = 個数」（持ち物）を書いて保存（Ctrl+Enter）。
2. 「実行：」でそのひな形を選んでから、「▶ このシーンから実行」。
3. ゲームの中のいまの値をひな形にするときは、デバッグ実行中の「ひな形に」か、コンソールの `preset 名前`。

| もっと使うとき | やり方 |
| --- | --- |
| もう一度同じように動かす | 「履歴 ▾」（最近の 10 件。よく使うものは「★ お気に入り」） |
| 二つのひな形の違いを見る | ひな形の窓の「比べる：」（「いつもの始まり」とも比べられる） |
| たくさんのひな形を整理する | 「組…」で組にまとめる、「片付け…」で使っていないものを寄せる・消す |
| ほかのプロジェクトへ持っていく | ひな形の窓の「書き出す…」「読み込む…」 |

**遊んでいるゲームとの行き来**

- 右上の「保存で読み直す」を入れると、デバッグ実行中のゲームが、保存したファイルを自動で読み直します。手で読み直すならゲームの中で F8（Shift+F8 でいまのシーンに入り直す）。
- ゲームの中のデバッグの「エディタで開く」（コンソールの `edit`）で、いま遊んでいるシーンや会話をこのエディタで開きます。

## キー操作

**シナリオエディタ**

| キー | 動き |
| --- | --- |
| Ctrl+S | 保存 |
| Ctrl+Z、Ctrl+Shift+Z・Ctrl+Y | 元に戻す、やり直す |
| Enter | 選んだカードを開く |
| F2 | 名前を変える |
| Delete | 削除 |
| Ctrl+A | カードをすべて選ぶ |
| Ctrl+クリック、Shift+クリック | カードを足す・外す、範囲で選ぶ |
| Ctrl+Space | 式エディタで候補を出す（↑↓で選び Enter・Tab で入れる、Esc で閉じる） |
| Ctrl+Enter | ひな形の窓で保存、読み込む窓で読み込む |
| Esc | 窓をやめる |

**デバッグ実行中のゲーム**

| キー | 動き |
| --- | --- |
| F6 | 調べられる場所を表示（`region` が絵と合っているか見る） |
| F8、Shift+F8 | 読み直す、読み直していまのシーンに入り直す |
| F11 | シーングラフ |
| F12 | デバッグコンソール（`vars`、`get`、`set`、`edit`、`reload` など） |

## 困ったとき

| こんなとき | 確かめること |
| --- | --- |
| 「adv80s」画面が出ない | プラグインが有効か。`addons/adv80s/plugin.cfg` がその場所にあるか |
| シナリオが一つも出ない | パンくずの「フォルダ」で、シナリオを置いたフォルダを選んでいるか |
| 古い形のファイルが「フォルダの外のファイル」になる | 右クリック →「シナリオのフォルダの形に移す…」 |
| 書いたものがゲームに出ない | 保存したか。実行中なら F8 か「保存で読み直す」 |
| 項目が赤字になっている | 素材・シーン・持ち物の ID が見つからない。一覧から選び直すか「ID の確認」で直す。素材なら「マニフェストを生成」を押したか |
| 式エディタで決定できない | 出ている理由を読む。括弧、`=` と `==`、文字列の引用符 |
| ID を変えたら Ink から移れなくなった | Ink の中の `goto_scene("…")` は書き換わらない。手で直して「Ink をコンパイル」 |
| Ink の変更が入らない | 「Ink をコンパイル」で `.ink.json` を作り直したか。`adv80s/inklecate_path` が正しいか |
| 「▶ このシーンから実行」で動かない | デバッグビルドか。シーンを開いているか |
| 間違えて消した | Ctrl+Z。エディタを閉じたあとなら OS のごみ箱（シナリオとチャプター） |

細かい決めごとは、リポジトリの `SPEC.md` の 6.8（シナリオエディタ）にあります。
